## Быстрая ориентация

- C# / **.NET 10**, xUnit, IoC со скоупами, генерация адаптеров Roslyn, действия из `.config`. Готовые `core.dll` и `scopes.dll` не изменять.
- `main` (`a3aecbf`) всё ещё содержит только каркас. Общая инфраструктура — `foundation/command-infrastructure` (`b51def2`). Наиболее полный **серверный стек** — `test/server-e2e` (`496c961`), с HTTP, JWT, снимками, переносом игр, управлением потоками и правами игроков.
- Полного приложения со всеми фичами в одной опубликованной ветке **нет**. Стрельба, движение, вращение, tanker-refuel, урон/столкновения, тики/обновление мира, объектная авторизация — отдельные ответвления. Наличие фичи в репозитории не означает её наличия в HTTP-приложении.
- `feature/bounded-load-routing` содержит самостоятельный вариант серверного стека с доработкой маршрутизации; свежие исправления соседних веток автоматически в него не попали.
- Проверенная интеграция сервера и игровых веток без тиков: **729/729**. Добавление world-update/game-ticks даёт **809/810** из-за архитектурного ограничения Scheduling. - Две разные системы прав: `Authentication/*` в `player-authorization` (JWT, команды/объекты игрока, владение) и `Authorization/*` в `object-authorization` (дерево областей и наследуемые разрешения). Автоматической связи между ними нет.

## Термины

`IGameItem` — словарь свойств; адаптер — узкий интерфейс к нему; Action — конфигурируемая макрокоманда; `ICommandContext` — роли нескольких объектов; `IBattleContext` — id боя и storage; quantum — бюджет одного исполнения игры; game tick — отдельно планируемый шаг мира, не синоним quantum; managed host — жизненный цикл игры, её поток, пауза, перенос и снимок.

## Поддержка документации

Сначала сверять refs с GitHub, затем код конкретного SHA. Описывать состав ветки и отличия от соседних, а не объединять найденные классы в воображаемую единую сборку. Новые цифры тестов получать свежим `dotnet test` в scratch-копии. Отсутствие конфликтов слияния само по себе не доказывает работоспособность. Не переносить факты старого аудита на новые tips без проверки.
