# Плагины игровых команд

Сервер загружает доверенные DLL, указанные в `Server:CommandPlugins`, при запуске до восстановления игр. Плагины работают в процессе сервера с его правами. Устанавливайте только сборки, которым доверяете.

Плагин реализует `SpaceBattle.Lib.ICommandPlugin` в публичном классе с открытым конструктором без аргументов. Сервер вызывает `Create` внутри скоупа игры после проверки прав на целевой предмет. Метод получает этот предмет и JSON-аргументы сообщения и возвращает обычный игровой `ICommand`. Один экземпляр плагина может создавать команды в разных играх одновременно, поэтому состояние отдельного вызова храните в возвращаемой команде.

## Пример Repair

Из корня репозитория соберите пример отдельно:

```sh
dotnet build SpaceBattle/Examples/RepairPlugin/RepairPlugin.csproj -c Release
```

Рядом с опубликованным сервером создайте каталог `plugins/repair` и скопируйте туда `RepairPlugin.dll`, `RepairPlugin.deps.json` и зависимости плагина, если они есть. Используйте ту же версию публичных контрактов `SpaceBattle.Lib`, что и сервер. Сервер предоставляет общую сборку контракта. Относительные пути в `CommandPlugins` считаются от каталога приложения.

Добавьте значения в раздел `Server` конфигурации. Сохраните существующие команды, виды предметов и права игроков, добавляя новые записи к ним:

```json
{
  "Server": {
    "CommandPlugins": ["plugins/repair/RepairPlugin.dll"],
    "AllowedCommands": ["CreateItem", "Repair"],
    "CommandTargets": { "CreateItem": "id", "Repair": "shipId" },
    "Players": { "pilot": { "Commands": ["CreateItem", "Repair"], "Items": ["ship-1"] } },
    "ItemKinds": { "Ship": ["Fuel", "Owner", "Health"] }
  }
}
```

Перезапустите сервер с той же сборкой. Создайте `ship-1` с владельцем `pilot` и целочисленным `Health`, затем отправьте в `POST /messages` с JWT игрока:

```json
{"gameId":"demo","command":"Repair","args":{"shipId":"ship-1","amount":3}}
```

`202 Accepted` означает постановку в очередь. Право на предмет проверяется при выполнении в игре. По умолчанию игрок может починить только свой корабль. При отсутствии DLL, конфликте имён или отсутствии настройки цели запуск прервётся. Сохраняйте доступность плагинов на серверах, которые восстанавливают снимки с соответствующими командами.
